# Changelog

## 5.0.0-rc2 — 2026-11-27

- PocketVault Android package `com.pocketvault.app`; Modern/Dark appearance default.
- Device pairing, automatic photo/video folder backups, SHA-256 content checking and deduplication.
- Verified signed APK installation, upload integrity, cancellation recovery, automatic backup and re-pairing.
- Logout requires `POST /api/device/revoke` on companion RC2 server.
- RC2 remains a **pre-release**: production hardening and one-command setup pending; Android gallery/recycle UI deferred.
